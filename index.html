瓶盖

使用方法

  1. 游戏内 Settings → Export Data 导出存档 JSON。
  2. 点击上方「导入存档」选择该文件。
  3. 修改宝可梦 / 道具。
  4. 点击「导出 JSON」，把文件放回游戏目录或用游戏内 Import Data 载入。

修改前请务必备份原始存档。本工具只在浏览器本地处理数据，不会上传任何内容。

校验规则

  • 等级 1–100、IV 0–6、经验 0–99（超过会连升）。
  • 招式必须是合法 move id；招式池不限制「是否是普通可学招式」。
  • 隐藏特性只能给有 `hiddenAbility` 的宝可梦解锁。
  • `saved.version` 只读，不会改动，避免触发版本迁移。
  • 未修改的字段原样保留。

iPhone / iPad 导入

iOS Safari 对游戏内的「Import Data」文件选择支持有问题，可能点击完全没反应。请改用游戏的 Data to Text：

  1. 在修改器点「复制文本」。
  2. 游戏内 Settings → Data to Text。
  3. 点 Paste；没反应就长按文本框手动粘贴。
  4. 点 Load，页面会自动刷新。

iOS 上「导出 JSON」可能只是打开预览而不是下载，复制文本更稳。

数据来源

宝可梦 / 招式 / 特性 / 道具名称由 pokechill 与 pokemon-dataset-zh 自动匹配生成；匹配不到的中文保持英文。形态词按官方译名拼接。
